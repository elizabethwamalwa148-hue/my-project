My Project

A school dashboard built with React and Vite.

 How to install

1. Clone the repository:
    open bush the run
   git clone https://github.com/elizabethwamalwa148-hue/my-project.git
   cd my-project

2. Install dependencies:

 Run npm install on bush


 How to run the whole project

 run npm run dev
Then open http://localhost:5173 in your browser.
